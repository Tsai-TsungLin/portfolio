# portfolio 進度

一列一個需求。狀態只有五種：**未做／進行中／已上線／待決定／不做**（「不做」一定寫理由）。
這個 repo 沒有版本 tag，所以「上線版本」欄填部署日期。
每次改了什麼看 `../CHANGELOG.md`；現行行為看 `01-design.md`，部署看 `02-deploy.md`。

**發版時只做三件事**：`CHANGELOG.md` 加一段、下面需求表的那一列填上線日期、發版紀錄加一行。
